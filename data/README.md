# Données

Les fichiers de données ne sont pas fournis avec le projet. Respectez les règles de confidentialité et les autorisations applicables avant toute utilisation.

- `raw/` : copies originales des sources, conservées sans modification. Les fichiers réels de ce dossier ne doivent pas être versionnés.
- `interim/` : résultats intermédiaires des futurs traitements.
- `processed/` : données préparées pour de futures analyses ou interfaces.

Les données réelles peuvent contenir des informations personnelles concernant les étudiants, les encadrants ou les organismes. Limitez leur accès, évitez leur diffusion et appliquez les règles de protection des données de l’établissement.
